# User Manual

## Login

Use the configured username and password.

## Dashboard

The dashboard displays:

- Total books
- Available books
- Total members
- Active borrowings
- Overdue books
- Today's returns

## Books

Use the Books tab to add, edit, delete, refresh, and search books.

## Members

Use the Members tab to register, edit, delete, refresh, and search members.

## Transactions

Use the Transactions tab to borrow and return books.

## Reports

Use the Reports tab to view:

- Popular books
- Overdue books
- Member activity
